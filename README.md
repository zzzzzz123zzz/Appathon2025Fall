## 🎯 What is Theo Health?

Theo Health transforms 🌟 **natural conversations** 🌟 into structured clinical data for patients with chronic conditions like cancer, Crohn's disease, autoimmune diseases, and long COVID.

No forms. No medical jargon. Just talk to Theo about your day, and let AI handle the rest.

## 🎬 Demo

<div>

**How Theo Health Works**

You: "Had a rough day. Pain was 7/10 in the morning, nauseous after lunch. Missed afternoon meds, felt low."

Theo: "I'm sorry today was tough. I've logged your pain, nausea, medication adherence, and mood. Want to talk more about it?"



**Theo automatically extracts:**
- Pain score: 7/10 (morning)
- Symptoms: Nausea
- Medication: Missed afternoon dose
- Mood: Low
- Timestamps: Entries tracked for patterns

*No manual entry—all handled by Theo!*

</div>

## 🚀 Quick Start

### Requirements

- Node 18+
- npm 9+
- React Native CLI

### Setup

git clone https://github.com/yourusername/theo-health.git
cd theo-health
npm install
npx expo start --tunnel --clear
